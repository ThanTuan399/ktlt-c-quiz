# CodeQuiz – Trắc nghiệm Kỹ thuật lập trình C

Ứng dụng ôn thi giữa kỳ dựa trên ngân hàng 233 câu hỏi 4 chương. Backend Node.js quản lý ngân hàng đề, lịch sử câu hỏi và đáp án; frontend HTML, CSS, JavaScript.

**Chạy:** `npm start` (Node.js 20+) và mở `http://localhost:3000`.

**Kiểm thử:** `npm test`.

Phân phối 40 câu/đề gồm 10 câu mỗi chương. Mỗi chương dùng hết lượt câu hỏi trước khi quay vòng, không trùng trong cùng mã đề. Có chấm từng câu và giải thích ngay sau khi trả lời.
